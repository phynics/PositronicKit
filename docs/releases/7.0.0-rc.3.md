# PositronicKit 7.0.0-rc.3

PositronicKit 7.0.0-rc.3 is a prerelease for consumer testing. Pin this exact tag while evaluating it. The stable 7.0.0 release remains pending.

Changes since rc.2:

- Hosts can read durable preparation diagnostics through `TurnHandle.diagnostics()`, including on replayed handles. The severity-policy refactor in #407 remains deferred.
- Workspace attachment reports configured-provider resolution failures and preserves the existing binding on failure or cancellation. A runtime without a Workspace factory keeps binding-only attachment. Register provider tool references before attaching a Workspace. Gnostic should verify this order against the candidate.
- Deleting a Workspace releases its cached provider. Detaching alone retains it for reuse.
- Provider endpoints preserve explicit ports unless the port is the default for that URL's scheme.
- OpenAI Chat Completions throws when a stream finishes with `tool_calls` and recovery yields no tool call.
- Workspace file search reports incomplete results when search bounds or unreadable files prevent a complete search.
- `TurnOutcome` is non-exhaustive. External Swift 6 consumers must include `@unknown default` in switches.
- The Turn EventHub wake test is deterministic, macOS memory-sampler shutdown handles exited-process-group `EPERM`, and release-candidate API checks use the current reviewed Next baselines on both platforms.

Live-provider cache-token evidence, the recorded OpenAI contract, Nix and downstream consumer lanes, iOS product evidence, dependency-update evidence, and final flake reports remain required before stable 7.0.0 under #316. Applicable consumer validation remains open under #283. Publishing this candidate does not close #412, #316, or #283.

Read the [7.0 migration guide](https://github.com/phynics/PositronicKit/blob/7.0.0-rc.3/docs/Migrating-to-7.md) before upgrading. The full [changelog](https://github.com/phynics/PositronicKit/blob/7.0.0-rc.3/CHANGELOG.md) includes earlier 7.0 changes.
